# Organização de Leituras

Aplicativo Flutter para cadastrar, listar, remover e atualizar o status de livros.

## Integrantes

- Leonardo Moya Fernandes
- Vinicius Silvestre

## Funcionalidades

- Lista persistente de livros
- Resumo da estante com contagem por status e total de livros
- Cadastro de título e autor
- Status: Quero ler, Lendo ou Concluído
- Avaliação de 1 a 5 estrelas e comentário curto para livros concluídos
- Remoção de livros
- Navegação entre telas
- Persistência com SharedPreferences
- Mensagens de confirmação

## Executar

```bash
flutter pub get
flutter run
```
